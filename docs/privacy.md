# Privacy Policy - Falcon ICP

**Last updated: October 31, 2026**

This policy describes the privacy practices of the Falcon ICP Android app and its interaction with the Falcon ICP server running on Windows. The app displays a virtual F-16 ICP panel, including its keypad and DED display, and is designed to work with the Falcon BMS flight simulator.

## Personal Information

Falcon ICP does not require an account. The app does not collect personal information to identify users or send data to the app developer. It does not create user profiles.

You enter the IP address and port of the server you want to connect to. The app uses these settings to establish the connection. During normal operation, simulator control data, such as ICP key presses, and information needed to display the DED may be sent to that server. This data is used only to operate the app and is not sent to the Falcon ICP developer.

## Server Connection

The app connects to the Windows server at the address configured by the user. Falcon ICP does not send any data to the app developer. As with any network connection, the server being contacted may receive the device's IP address and information necessary to handle the communication.

## Permissions and Data Deletion

The app uses network access to connect to the configured server. It does not require access to your location, contacts, camera, microphone, or device files.

The app developer does not store user data, so there is no user data held by the developer to delete. Settings saved locally on your device can be removed by clearing the app's data or uninstalling the app.

## Children's Privacy

Falcon ICP does not collect personal information from users, including children.

## Changes to This Policy

This policy will be updated if the app's functionality or privacy practices change. The latest version will be published at the address where this document is made available.
